Sudoku Game — это настольное приложение-головоломка, разработанное с использованием Windows Forms на C#. 
Игроку предлагается классическая сетка 9x9, разделённая на блоки 3x3. 
Некоторые ячейки уже заполнены, и задача игрока — завершить заполнение так, чтобы каждая строка, 
каждый столбец и каждый блок 3x3 содержал все цифры от 1 до 9.
Основные классы:
SudokuGenerator: логика генерации валидного поля 9x9 с заполнением диагональных блоков и последующим решением.

SudokuForm: основная игровая форма.

Метод GenerateSudokuField() создаёт поле 9x9 с отступами между блоками 3x3.

Обработчики:

ResetButton_Click — генерирует новое поле.

CheckButton_Click — проверяет правильность заполнения поля.

MainMenuButton_Click — возвращает в главное меню.

Form1 или MainForm: стартовое окно игры.

RoundButton: пользовательский элемент управления для создания круглых кнопок.

Основные задачи
 Генерация валидного поля Sudoku

 UI для отображения и редактирования поля

 Кнопка Reset — перегенерация поля

 Кнопка Check — проверка решения и отображение результата

 Экран результата

 Кнопка возврата в главное меню
